Limitations and how to read this

What this report is

Reproducible, signed evidence from automated analysis of one commit, mapped to named controls, with a concrete fix for each finding.

What it is not

It is not a certification and not a conformity assessment. Only an accredited body can certify, and only a manufacturer can declare conformity. Control mappings here are indicative and need review against the current standard text.

Known blind spots

  • Automated analysis does not find design flaws, business-logic errors or broken access control. Pair this with threat modelling, design review and a penetration test - and record them as attestations so they appear in this report.
  • Findings are evidence about one commit on one machine at one moment. Re-scan on every release; the trend line is the real product.
  • Static analysis produces false positives. Accept them deliberately, with a reason and an owner, rather than silencing them.
  • A tool that is not installed cannot see anything. Check the scope section before reading a clean result as a good one.
